# Rozaneh Tab — Project Brief

## What this is

A new-tab browser extension (Chrome + Firefox, Manifest V3) inspired by Rooza
(rooza.space) feature-for-feature, but with original branding ("Rozaneh Tab", not
"Rooza"), built with the minimum possible permissions and maximum lightness.
Bilingual UI (Persian RTL default, English toggle). Tri-calendar support
(Jalali / Hijri / Gregorian).

## Stack

- WXT (Vite-based extension framework)
- Svelte 5 (runes, no virtual DOM)
- TypeScript
- pnpm
- Tailwind CSS v4 (utility classes only, no custom plugins unless required)
